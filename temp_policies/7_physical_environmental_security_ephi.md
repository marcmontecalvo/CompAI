# Physical and Environmental Security for ePHI

**Policy Type**: HIPAA Security Policy
**Frequency**: Yearly Review
**Department**: IT/Facilities
**Status**: ⚠️ NEEDS COMPLIANCE WRITER

---

## Coverage

This policy consolidates requirements for the following HIPAA Security Rule controls:
- **Control 12**: Physical Facility Access Controls for ePHI

---

## Purpose

**[POLICY CONTENT TO BE COMPLETED BY COMPLIANCE WRITER]**

This policy should establish physical and environmental security controls to protect ePHI including:
- Facility access controls for areas housing ePHI systems
- Physical safeguards for server rooms and data centers
- Workstation placement and physical security
- Device and media controls
- Visitor access and escort procedures
- Physical security monitoring and audit
- Environmental controls (fire, flood, temperature, power)
- Maintenance of physical security systems

---

## Scope

**[TO BE COMPLETED]**

Should apply to:
- All facilities where ePHI is created, received, maintained, or transmitted
- Server rooms and data centers containing ePHI systems
- Network equipment rooms
- Workstations and devices accessing ePHI
- Physical media containing ePHI (hard drives, backup tapes, USB drives)
- Third-party data centers and colocation facilities
- Remote work locations (home offices)

## Policy Statements

**[TO BE COMPLETED - See guidance below]**

### Required Sections:

#### 1. Facility Access Controls
- Badge access system for ePHI areas
- Access levels and authorization
- 24/7 monitoring and logging
- Access review procedures
- Lost/stolen badge reporting
- Badge return upon termination

#### 2. Server Room and Data Center Security
- Physical access restrictions (authorized personnel only)
- Biometric or two-factor access controls
- Video surveillance with retention
- Environmental monitoring (temperature, humidity, water)
- Fire suppression systems
- Uninterruptible Power Supply (UPS) and backup generators
- Secure equipment installation (racks, cable management)

#### 3. Workstation Physical Security
- Workstation placement away from public view
- Privacy screens for workstations in shared spaces
- Screen locks (automatic timeout)
- Clean desk policy for ePHI documents
- Secure storage for ePHI printouts
- Workstation cable locks for mobile devices

#### 4. Device and Media Controls
- Secure storage for portable media (USB drives, external hard drives)
- Media disposal procedures (wiping, shredding, destruction)
- Tracking of media containing ePHI (inventory)
- Prohibition of unauthorized media use
- Encryption requirement for portable media
- Secure shipping procedures for media containing ePHI

#### 5. Visitor Access and Escort Procedures
- Visitor sign-in and badge issuance
- Escort requirement for visitors in ePHI areas
- Visitor badge return and sign-out
- Vendor access procedures and authorization
- Contractor background checks
- Visitor access log retention

#### 6. Physical Security Monitoring
- Video surveillance in critical areas
- Badge access log review (quarterly)
- Alarm systems and intrusion detection
- Security personnel or monitoring service
- Incident response for physical breaches

#### 7. Environmental Controls
- Fire detection and suppression (sprinklers, gas systems)
- Water detection sensors in server rooms
- HVAC systems with temperature monitoring
- Power redundancy (UPS, generators, dual power feeds)
- Regular testing of environmental systems
- Emergency shutdown procedures

#### 8. Physical Security System Maintenance
- Regular testing of badge access systems
- Camera maintenance and functionality checks
- Fire/water detection system testing
- Generator and UPS testing and maintenance
- Vendor service contracts and documentation

#### 9. Remote Work Physical Security
- Secure home office requirements
- Prohibition of ePHI access in public spaces
- VPN requirement for remote ePHI access
- Physical security of remote devices
- Return of devices upon termination

## Procedures

**[TO BE COMPLETED]**

Should include detailed procedures for:

### Provisioning Facility Access
1. Access request by manager
2. Business need justification
3. Badge issuance by security/facilities
4. Access level assignment
5. Initial access audit at 30 days

### Quarterly Facility Access Review
1. Pull badge access logs for ePHI areas (last 90 days)
2. Identify after-hours access
3. Identify terminated employee badge use
4. Investigate anomalies
5. Manager recertification of team access
6. Remediate inappropriate access
7. Document review and findings

### Visitor Access Procedure
1. Visitor arrival and sign-in
2. Photo ID verification
3. Visitor badge issuance
4. Escort assignment
5. Access limited to authorized areas
6. Visitor badge return and sign-out
7. Log retention (6 years)

### Physical Security Incident Response
1. Incident detection (alarm, surveillance, report)
2. Security team notification
3. Incident investigation
4. ePHI impact assessment
5. Corrective actions
6. Incident documentation
7. Breach determination (if ePHI involved)

### Environmental System Testing
1. Monthly generator testing
2. Quarterly UPS testing
3. Semi-annual fire suppression testing
4. Annual environmental system inspection
5. Maintenance vendor documentation
6. Test results documented

## Physical Security Standards

**[TO BE COMPLETED]**

### Badge Access System Requirements
- Multi-technology badge reader support
- Real-time access logging
- Remote lock/unlock capability
- Integration with HR system for terminations
- Audit trail retention (6 years)

### Video Surveillance Requirements
- Coverage of all entry/exit points
- Server room coverage
- Minimum 30-day retention (90 days for ePHI areas)
- Recording quality standards
- Secure storage of video footage

### Environmental Standards
- Server room temperature: 64-80°F (18-27°C)
- Server room humidity: 45-55% relative humidity
- UPS runtime: Minimum 30 minutes at full load
- Generator activation: Within 30 seconds of power loss

## Notes for Compliance Writer

Physical security is often overlooked but is a Required Implementation Specification under HIPAA. Key considerations:

1. **Risk-Based Approach**: Tailor physical controls based on facility type (office, data center, clinic)
2. **Integration**: Physical and logical access controls should be integrated (badge + credentials)
3. **Third-Party Facilities**: If using colocation or cloud providers, obtain their physical security documentation
4. **Workstation Placement**: Simple measure like positioning monitors away from windows/public view
5. **Media Disposal**: Secure destruction is critical - retain certificates of destruction
6. **Remote Work**: With hybrid work, address physical security of home offices
7. **Environmental**: Power and cooling failures can impact ePHI availability (contingency planning)

Coordinate closely with Facilities Management to ensure alignment with existing physical security programs.
