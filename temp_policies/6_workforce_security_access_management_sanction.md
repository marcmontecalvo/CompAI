## Coverage

This policy consolidates requirements for the following HIPAA Security Rule controls:
- **Control 3**: Workforce Access Termination & ePHI Security
- **Control 4**: Workforce Clearance and Access Authorization
- **Control 15**: ePHI Access Authorization & Role-Based Controls
- Access Rights management

## Policy Statements

**[TO BE COMPLETED - See guidance below]**

### Required Sections:

#### 1. Workforce Clearance Procedures
- Pre-employment background checks for ePHI access roles
- Screening requirements (criminal, education, references)
- Re-screening frequency for high-risk roles
- Documentation and retention of clearance records
- Third-party screening vendor requirements

#### 2. Access Authorization and Approval
- Formal access request process
- Manager approval for ePHI access
- Business justification requirements
- IT Security Officer review and approval
- No ePHI access before HIPAA training completion
- Documentation of authorization decisions

#### 3. Role-Based Access Control (RBAC)
- Definition of standard ePHI access roles (clinical, administrative, support)
- Role-to-permission mapping
- Minimum necessary principle enforcement
- Role assignment criteria based on job function
- Role modification procedures

#### 4. Minimum Necessary Principle
- Access limited to ePHI required for job duties
- "Need to know" basis for all ePHI access
- Prohibition of unnecessary ePHI browsing
- Break-glass emergency access procedures
- Audit of access patterns to verify appropriateness

#### 5. Periodic Access Review and Recertification
- Quarterly manager attestation of team ePHI access
- Annual comprehensive access review
- Exception investigation and remediation
- Access removal for role changes
- Documentation of recertification outcomes

#### 6. Workforce Termination Procedures
- Immediate access revocation upon termination
- Termination checklist (badge, credentials, devices)
- HR notification to IT Security
- Return of all company property containing ePHI
- Exit interview with security reminders
- Post-termination monitoring of former employee accounts

#### 7. Sanctions for HIPAA Violations
- Progressive discipline policy
- Violation categories (minor, moderate, severe)
- Investigation procedures
- Sanction determination criteria
- Documentation of sanctions applied
- Workforce awareness of sanction policy

#### 8. Credential Management
- Unique user IDs (no shared accounts)
- Credential provisioning and deprovisioning
- Password/MFA requirements
- Credential suspension for leaves of absence
- Re-enablement procedures upon return

## Procedures

**[TO BE COMPLETED]**

Should include detailed procedures for:

### Onboarding Procedure
1. Background check completion and approval
2. New hire orientation with HIPAA training
3. Access request submission by manager
4. Access approval by IT Security Officer
5. Credential provisioning
6. Initial access review at 90 days

### Access Request Procedure
1. Manager submits access request form
2. Business justification documented
3. RBAC role assignment
4. Minimum necessary verification
5. IT Security Officer approval
6. Access provisioned within 24 hours

### Quarterly Access Recertification
1. Generate access reports by manager
2. Managers review and attest to team access
3. Identify inappropriate access
4. Remediate access issues
5. Document recertification
6. Report to HIPAA Security Officer

### Termination Procedure
1. HR notifies IT Security of termination
2. Immediate credential deactivation
3. Badge and device recovery
4. Access verification (all systems)
5. Termination checklist completion
6. 30-day post-termination audit

### Sanction Procedure
1. Violation identified (audit, report, incident)
2. Investigation initiated
3. Findings documented
4. Sanction determination (Security Officer + HR)
5. Sanction applied (warning, suspension, termination)
6. Documentation maintained for 6 years
7. Workforce notification (if appropriate)

## Notes for Compliance Writer

This policy addresses critical workforce security requirements. Key considerations:

1. **Background Checks**: Define what level of background check is required (state/federal criminal, education, references)
2. **Termination SLA**: Immediate access revocation is critical - define specific timeframes
3. **Manager Accountability**: Managers are accountable for their team's access appropriateness
4. **Sanction Consistency**: Ensure sanctions are applied consistently to avoid discrimination claims
5. **Legal Review**: Have labor attorney review sanction policy to ensure compliance with employment law
6. **Documentation**: All access decisions, recertifications, and sanctions must be documented
7. **Integration**: Coordinate with existing HR policies on progressive discipline

This policy requires close collaboration between HR, IT Security, and Legal to ensure both HIPAA compliance and employment law compliance.
